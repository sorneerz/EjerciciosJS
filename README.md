# EjerciciosJS
Menú interactivo en HTML y JavaScript con ejercicios de lógica matemática (números primos, divisores y capicúas) para el Taller de Introducción a la Ingeniería de Sistemas. 

# Taller de Lógica - Introducción a la Ingeniería de Sistemas

Este proyecto es un menú interactivo desarrollado con **HTML** y **JavaScript** que implementa varios algoritmos de lógica matemática y validación numérica.

## 🚀 Funcionalidades del Menú
El programa cuenta con una interfaz web basada en botones que ejecuta los siguientes módulos:
1. **Divisor:** Comprueba si el segundo número es divisor exacto del primero[cite: 3].
2. **Es primo:** Determina mediante un algoritmo matemático si un número ingresado es primo[cite: 3].
3. **Divisores primos:** Encuentra todos los divisores primos de un número entero positivo[cite: 3].
4. **Primeros N Primos:** Genera una lista con los primeros $N$ números primos solicitados[cite: 3].
5. **Aleatorio primo:** Genera un número al azar entre 1 y 100 y verifica si es primo[cite: 3].
6. **Números capicúas:** Busca y muestra 10 números capicúas de 3 cifras generados aleatoriamente[cite: 3].

## 💻 Tecnologías utilizadas
* **HTML5** (Estructura y diseño básico)
* **JavaScript** (Lógica de programación, bucles, arreglos y funciones)

## 🏃‍♂️ ¿Cómo probarlo?
1. Descarga el archivo del repositorio.
2. Abre el archivo `.html` directamente en cualquier navegador web (Google Chrome, Edge, Firefox, etc.).
3. Haz clic en los botones del menú para interactuar con las alertas de JavaScript.
